# 执行交接包模板

复制为`docs/handoffs/<batch-id>-r<n>.md`，不要覆盖旧revision。用户原文、token/key、二维码、provider私有地址和原生库内容不写入公共Git。

## 批次身份与状态

- batchId / revision：
- 状态：WIP / READY_FOR_REVIEW
- 执行AI真实App/线程或引用 / branch / cwd：
- 已读并确认协作协议：是/否；允许写入的文件：
- 对应M/B/T、V case、C裁剪项：
- 本批目标及明确不做的事项：

## 固定来源

- base HEAD / commit或PR / dirty sourceRef：
- 新建、修改、删除、rename逐文件列表与SHA256：
- 直接依赖、测试配置、lock、实际运行bundle/image的版本：
- 这些来源已冻结；可继续变化但不影响本批的文件：
- 自测前后sourceRef是否一致：
- 历史共享未提交内容与本批新增区别：

| 要求/Case | 当前实现 | 验证命令/API与cwd | 退出码/断言/效果计数 | evidenceRef | 尚未覆盖 |
| --- | --- | --- | --- | --- | --- |
| 待填 | 待填 | 待填 | 待填 | 待填 | 待填 |

- 真实模型/原文外呼/生产读写/原生会话/微信外发：具体发生或未发生；权限依据：
- 失败、部分结果和不明副作用：
- 活动进程/job/handle及最近实际poll结果（没有则无）：

- 实现完成、自测通过、独立审计、部署/真机：分别填状态，不合并成“全部完成”。
