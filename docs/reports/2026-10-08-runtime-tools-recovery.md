## B 重启后不能盲目重做

| 原策略 / 当前策略 | 实际SIGKILL后行为 |
| --- | --- |
| safe / safe | 重放；稳定effect key不增建任务 |
| safe / unsafe | 停止；保留中断输出 |
| unsafe / safe | 停止；保留中断输出 |
| unsafe / unsafe | 停止；保留中断输出 |

测试杀死的是专用测试进程，不是线上服务。
这验证公开SDK和合成效果，不代表原生派单已接通。

真实Kimi只读测试已通过现役及临时修复转接层。
每次两轮HTTP200，保存一个查询。
总usage为536–539 token。
重复和重开没有额外模型调用，产品状态未变。
早期失败如实保留，不计成功。
