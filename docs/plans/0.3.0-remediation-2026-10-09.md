## 3. S01：三项快照缺陷的最小解决方案

### SN-F002：目标路径必须属于本轮且不能覆盖

- `store.name` 与 `runId` 都限定安全单段，拒绝 `.`/`..`、分隔符、NUL、保留名与内部 stage/manifest 名称冲突。继续保持名称唯一。
- 在首次写入前计算每个目标及暂存路径，校验相对本轮目录的 containment、祖先 symlink 与目标不存在；不能只检查 rootDir。
- 由编排层独占预留本轮 namespace；最终提交不得覆盖旧目标。若并发替换不能安全排除，应明确受支持的单 writer/owner 条件并拒绝不满足者，不能把 exists 检查当原子保证。
- 验收：`../victim`、嵌套路径、保留名、已有目录、symlink/别名、并发目标竞争均拒绝；拒绝前源/目标的内容、inode、mode 不变。正常 sqlite/filedir/custom adapter 路径保持。

### SN-F001：暂停结果未知必须可核对

- 先持久化 `quiesce-intent`，再调用 adapter；按 store 记录状态，而非 await 成功后才加入唯一恢复列表。
- 扩展现有适配协议，携带 runId、owner/fence、幂等 operationId。区分未调用、确认暂停、结果未知、确认恢复、恢复失败。
- `quiesce()` 抛错不代表未暂停。未知结果进入 `needs-review` 并阻止切换；通过原 owner/fence 的状态核对和幂等恢复处理。禁止对未知 owner 盲目 resume。
- journal 支持重开核对；旧 owner 或过期 fence 不能恢复别人的 store。manifest 如实区分 attempted/confirmed，不把未确认暂停写成 skipped。
- 验收：暂停前失败、暂停后失败/断链、暂停后 SIGKILL、重开、恢复失败、stale fence；未受影响的已确认 store 仍按约定清理。不明状态不能返回 success，也不能自动重新执行用户任务。

### SN-F003：清单不得持久化任意错误文本

- 建立固定错误 code/stage 和经验证的 store 逻辑 ID 白名单；未知异常映射为固定 `adapter-failed` 等代码。
- 不序列化任意 name/message/stack/cause/String(error)，不能仅依赖正则遮罩或 500 字截断。
- 验收：三个 adapter 阶段、写 manifest 阶段分别注入合成凭据、路径、用户正文与嵌套 cause。公开清单、返回 DTO、日志均不含 canary；保留可定位错误码。

交付 `docs/handoffs/p6-snapshot-orchestrator-r2.md`：逐项 Finding 应答、源码/直接依赖完整 hash、旧反例与新断言、原始退出码、未覆盖范围。三个缺陷可在同一包修复，不拆成三套编排器。

## 4. S02：把重启准备变成可验证的部署包

- 复用 identity-pairing/exportPrincipals/writeAuthorityFile。生成候选 Goal/Memory authority 与客户端映射；绑定用户命名空间、最小角色、有效期、撤销关系。秘密只写私有位置，公开记录不含 token。
- 不只检查默认路径：解析实际服务环境覆盖、launchd 参数、客户端 tokenFile、文件 owner/mode/无 symlink。候选文件与配置先在独立 stateDir/端口验证。
- 覆盖微信 bridge、Goal client、Memory client、UI 服务端代理；浏览器不得获得私有 token。禁止签发一把共用 operator token 图省事。
- 部署预检需同时检查 health 与已认证业务：合法成功、未知/过期/吊销 401、低角色写 403 且零变更、缺坏 authority 明确失败；轮换不重启生效。
- 配置升级显式处理 `promptTimeoutMs=300000`。缺新值时迁成同等 300000ms 操作上限，输出弃用提示；若新旧值冲突则拒绝并要求确定值，不静默采用 30min 默认。不能改变正式 Grant 的绝对期限。
- 验收包括两次 dry-run 一致、未知键、非法时间、客户端漏映射、配置回滚；候选路径不得触现役状态。具体迁移器入口由执行方交付后登记，本文不虚构可运行命令。

## 5. S03：从组件接到真实执行

- 用宿主的正式 Grant 绑定 task/execution、owner、参数摘要、scope 和 `expiresAt`。在准入时确定有效截止点为所有适用上限的最早值，入队前持久化；恢复和 fallback 只继承，不重新盖章延长。
- 缺失/非法/过期 Grant 拒绝真实 dispatch。前台等待超时仅改变通知，不取消已获准后台工作；Grant 到期必须停止新派发并结算已发工作的确定/未知结果。
- 将 createSession 候选链纳入同一故障策略：认证故障、未知启动效果、权限错误不得以“尚未 prompt”为理由自动换模型重试。
- 宿主分配独立私有 scratch，禁止与 workspace 双向重叠。固定验收脚本与待审 artifact 只读；依据真实 CLI 所需元数据最小开放，不直接授权整个用户目录。
- 当前 RO 只覆盖 native-acp：其他路径在证明同等只读前，不路由 Reviewer 到该路径。首条链路限定已验证路径，不伪称所有 Agent 已支持。
- 验收：排队过期、重启过期、clock 非法、fallback 截止点不变、两类取消边界、只读 OS 正负例、认证故障零重派、未知 launch 不重放。保持已通过的 FG/RO 原反例。

## 6. S04：记忆、停写与回退的跨层完整性

- 隐私重置：epoch 查询失败时 hold/needs-review，不能保留旧上下文继续生成或投递；异步过程在生成/投递边界重新核对。内部会话可按已知 epoch 过滤重建；不静默删除原生历史、kill/replay 在飞任务。
- 质量 UI：实际状态接口使用服务端认证 POST 代理，绑定命名空间，只返回最小状态 DTO；不把私有 token/原文/quote/私有路径/tombstone hash 给浏览器。
- 旧记录外呼：先生成本地出站字段/目的 provider/调用上限清单和 secret-screen dry-run。当前 evaluator 可能发送完整 user_text，必须如实披露；若批准范围仅最小 quote，就先修改实现并测试后再调用。失败保留 needs-review，不把旧状态批量改为 validated。
- 不把历史 113 回执/43 用户记录当固定数量或独立事实数；执行前只读重盘点，用户与助手数据分开处置。语义外呼、私有副本迁移、生产迁回分别留证。
- 复用现有 store 接口实现注入式 transport 的真实适配器。按固定 lock 顺序停止新准入、drain/核对 in-flight、记录共同 freeze watermark 与 owner/fence，再快照。单库 backup 不等于跨 store 同一冻结点。
- 将测试内 restore 原型收敛为受控生产路径。预检全部目标与 manifest，保存切换后增量；检测 watermark 漂移即拒绝覆盖。回退仅切未来路由，未知旧 execution 不重放；不可将旧备份覆盖新回执/记忆。
- 用合成 store/可注入 transport 验证双 dry-run、四类 store 守恒、停写超时、部分失败、恢复重开、回退中断、切换后有新数据。逐文件 rename 不可宣称跨 store 原子提交。

## 7. S05/S06：真实测试、生产与既有授权如何衔接

用户此前明确要求“核对并授权”。不把该意愿记录成用户未作决定；但执行前必须把目标、路径、账号、数据出站字段、有效期和已有预算落实到匹配的 Approval/Grant，不能由实现 AI 冒充 operator 自签。只针对缺失的具体范围补确认。

- **技术取舍**：0.3.0 先以现有 CLI/ACP 核心推进；Paseo 可选路径未通过来源/许可/NOTICE 核验前不纳入默认发布承诺。上游根 Apache-2.0 与包缺 license 字段应分别记录，不能等同“无许可”，不修改第三方 metadata 伪造结论。
- **权限收紧**：使用已有精确清单，重核 owner/type/no-symlink/mode/ACL，逐项记录旧值；目录 0700、敏感文件 0600；不递归、不碰其他 App 配置。清单漂移停该项，不连带阻塞源码。
- **真实 CLI**：先新建专用合成测试会话，使用已批准 provider/账号与原预算；不恢复用户旧会话，不自动扩大网络/文件权限。尝试失败核对作用再决定，不能不明状态换 ID 重跑。最终仍须至少两种 CLI 达标。
- **真微信**：只向匹配批准的测试用户投递；测试文字/语音、短等待转后台、取消、断链、补发。记录 Execution 数和 Outbox attempt，补发只投递不重执行。
- **生产前**：冻结候选 artifact/config/依赖 hash；完成备份、drain/未知任务清单、身份映射和业务预检。先单白名单 canary，异常停止新准入并核对，不一键全量重启。
- **24h**：从真实 canary 成功开始计时。记录电源、合盖、实际 suspend/wake、网络切换、期限与恢复；睡眠期不声称持续执行。中断/修复分段留痕，不能用快速 fake 时钟代替。
- **alert #1**：处置前只读复核仍是同一上游合成样例；确认为 false positive 后按该具体授权关闭这一条。不得顺带 dismiss 其他告警、改历史或轮换真实 key；报告不能暴露 secret 本体。

任何生产前置不满足，保留旧已运行版本，不用关闭 fail-closed 安检取得健康。首次真实测试、生产 canary、正式发布是不同门槛。
